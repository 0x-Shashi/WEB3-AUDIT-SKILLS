# WEB3-AUDIT-SKILLS for Antigravity

Antigravity CLI configuration for Web3 security auditing skills.

## Installation

1. Clone this repo to your Antigravity skills directory
2. Configure Antigravity to load the skills

## Skills Available

- **Attack Trees** - Protocol-specific vulnerability decision trees
- **Anti-Patterns** - Bad code patterns with fixes
- **Patterns** - Secure implementation patterns
- **Exploit Forensics** - Real hack analysis
- **Protocol Playbooks** - Integration security guides
- **Templates** - Audit session templates

## Usage

Load skills based on protocol type:

```
/load attack-trees/lending-attack-tree.md
/load anti-patterns/oracle-anti-patterns.md
```

## Configuration

See `antigravity.yaml` for hooks and tool permissions.
