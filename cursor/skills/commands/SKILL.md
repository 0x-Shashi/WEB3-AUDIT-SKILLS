# Commands Skill

## Purpose
Provides structured command patterns for invoking audit capabilities through the plugin.

## Available Commands
- `/audit <contract>` - Run comprehensive audit
- `/scan <contract>` - Quick vulnerability scan
- `/checklist <type>` - Load protocol-specific checklist
- `/report` - Generate audit report
- `/severity <finding>` - Classify finding severity
- `/patterns <category>` - Browse vulnerability patterns
- `/chain-guide <chain>` - Load chain-specific security guide
