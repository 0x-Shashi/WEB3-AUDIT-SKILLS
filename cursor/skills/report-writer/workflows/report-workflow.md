# Report Generation Workflow

## Steps
1. **Collect findings**: Gather all identified vulnerabilities
2. **Classify severity**: Apply severity matrix to each finding
3. **Write descriptions**: Clear, concise explanation of each issue
4. **Create PoCs**: Write proof-of-concept for Critical/High findings
5. **Write recommendations**: Specific fix for each finding
6. **Executive summary**: Summarize overall security posture
7. **Review**: Internal quality check on all findings
8. **Format**: Apply report template and professional formatting
9. **Deliver**: Export as PDF/Markdown
