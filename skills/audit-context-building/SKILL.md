# Audit Context Building Skill

## Purpose
Systematically build comprehensive understanding of a protocol before diving into code-level analysis.

## Capabilities
- Architecture mapping (contract relationships, inheritance, dependencies)
- Function-level analysis (access control, state changes, external calls)
- Protocol invariant identification
- Trust boundary mapping
- External dependency assessment
