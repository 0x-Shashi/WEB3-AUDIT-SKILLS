# Context Building Completeness Checklist

## Before Starting Audit
- [ ] All contracts identified and inventoried
- [ ] Inheritance tree mapped
- [ ] External dependencies listed with versions
- [ ] Deployment chain(s) identified
- [ ] Compiler version and settings noted
- [ ] All privileged roles documented
- [ ] Token flow mapped (in/out/internal)
- [ ] Protocol invariants identified
- [ ] Previous audits reviewed (if any)
- [ ] Test suite reviewed for coverage gaps

## Understanding Verification
- [ ] Can explain protocol purpose in one sentence
- [ ] Can describe typical user flow end-to-end
- [ ] Can identify top 3 risk areas
- [ ] Can name all external integrations
- [ ] Know which functions handle the most value
