# Aztec Scanner Skill

## Purpose
Analyze Aztec Network (Noir) contracts for privacy and security vulnerabilities.

## Detection Capabilities
- Privacy leaks in note management
- Nullifier collision attacks
- Public/private state synchronization issues
- Oracle callback vulnerabilities
- Access control in private functions
- Encryption key management

## Overview
Aztec is a privacy-focused L2 with:
- Private and public state separation
- UTXO-like note model for private data
- Noir language for circuit programming
- Encrypted function arguments
