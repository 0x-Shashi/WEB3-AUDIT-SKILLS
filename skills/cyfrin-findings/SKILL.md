# Cyfrin Findings Database Skill

## Purpose
Query and leverage the Cyfrin/Solodit findings database for vulnerability research and audit enhancement.

## Capabilities
- Search past audit findings by protocol type
- Find similar vulnerabilities to suspected issues
- Research attack patterns from real exploits
- Build vulnerability knowledge base
- Pre-development security research
